# 辅助脚本说明

包里带了两个脚本（`scripts/`），都是可选的便利工具，不装也不影响主流程。

| 脚本 | 作用 |
| --- | --- |
| `scripts/run.py` | 定位一个可用的 campusnet 并调用它 —— 省去自己判断 `python`/`python3`、拼 `PYTHONPATH`。也适用于"源码在本地但没 `pip install`"的情况 |
| `scripts/fingerprint.py` | 生成**自动脱敏**的校园网指纹报告，可直接粘贴到 GitHub issue |

用法：

```sh
python3 scripts/run.py doctor
python3 scripts/fingerprint.py --no-save
```

下面把**脱敏规则**单独写出来 —— 一是让你能核对脚本到底做了什么
（平台要求"代码逻辑透明"），二是脚本跑不起来时也能照着手工处理。

---

## 一、脱敏规则

交给别人看之前，必须处理掉这四类信息：

| 类型 | 怎么做 |
| --- | --- |
| **账号** | 学号/工号这类连续 6 位以上的数字，只留前 2 位，其余换成 `*`（`2200000000` → `20********`） |
| **IPv4** | 整段替换成 `x.x.x.x`。想保留"是内网"这个信息就写成 `172.16.x.x`（只留前两段），**不要**留全 |
| **MAC** | 整段替换成 `xx:xx:xx:xx:xx:xx`。注意有的工具输出的是去掉冒号的 12 位十六进制（`001122334455`），这种也要替换 |
| **密码** | `upass=`、`password=`、`pass=`、`pwd=`、`CAMPUSNET_PASSWORD=` 等赋值语句右侧全部换成 `******` |

**两个容易做错的地方：**

1. **协议常量不要打码。** `0MKKey=123456`、`ac_id=1`、
   `R1=0`、`para=00` 这些是协议固定值，不是个人信息。
   笼统地"把长数字都打码"会把它们打成 `12****`，报告反而没法看。
2. **只信任脚本、不信任自觉。** 手工打码一定会漏，能跑脚本就跑脚本。

脱敏完**自己再扫一眼**再发出去 —— 自动处理覆盖常见形态，不保证零遗漏。

## 二、一条命令手工复现认证（排障用）

绕开所有代码，直接打一次认证接口 —— 这是切开
"网络问题"和"程序问题"最快的方法：

```sh
uclient-fetch -q -O - "http://门户地址/drcom/login?callback=dr1003&DDDDD=学号&upass=密码&0MKKey=123456&R1=0&R2=&R3=0&R6=0&para=00&v6ip=&v=$(date +%s)"
```

或者用 `curl`：

```sh
curl -s "http://门户地址/drcom/login?callback=dr1003&DDDDD=学号&upass=密码&0MKKey=123456&R1=0&R2=&R3=0&R6=0&para=00&v6ip=&v=$(date +%s)"
```

期望返回 `dr1003({"result":1,...})`：

| `result` | 含义 |
| --- | --- |
| `1` | 成功 |
| `2` / `3` | 已经在线（也算成功） |
| 其它 | `msga` 字段里有失败原因 |

`python3 -m campusnet doctor` 会把这条命令按你的实际配置拼好，照抄即可。
